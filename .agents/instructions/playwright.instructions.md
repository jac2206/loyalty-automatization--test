# Instrucciones Playwright

- Usar `test`, `expect`, `request` y `page` de `@playwright/test`.
- Ejecutar un test específico antes del grupo completo.
- Usar `test.step` para separar request, validación de status y validación del body.
- Aprovechar screenshots y traces configurados para investigar fallos.
- Mantener el proyecto Chromium salvo que exista un requisito explícito para otro navegador.
