# Instrucciones para agentes IA

- Inspeccionar `src` y `playwright.config.ts` antes de proponer cambios.
- Trabajar solo con Playwright, TypeScript y las dependencias existentes.
- No inventar endpoints ni contratos; usar los tests y respuestas observadas.
- No copiar secretos del `.env`.
- Seguir la estructura `data → fixtures → services → tests`.
- Informar qué tests fueron ejecutados y cuáles dependen de un ambiente externo.
