# Instrucciones de contratos y Swagger

Este repositorio consume una API; no posee actualmente el código fuente de Swagger/OpenAPI. Cuando exista una especificación publicada, usarla como fuente primaria para métodos, rutas, parámetros, autenticación, respuestas y schemas.

No generar documentación Swagger dentro de este proyecto sin una solicitud explícita. Si el contrato documentado difiere del ambiente, registrar la discrepancia en la spec correspondiente.
